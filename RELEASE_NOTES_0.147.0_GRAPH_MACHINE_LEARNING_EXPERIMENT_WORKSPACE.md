# Release Notes — Lab v0.147.0

## Graph Machine Learning Experiment Workspace
This release adds the graph-ML experiment layer on top of v0.146.0 Graph & Network Science Research Workspace.

Key additions include governed task/dataset/split/model/run/prediction objects; node, edge, and graph prediction results; candidate-only link prediction; anomaly and embedding results; GNN explainability; graph-specific leakage and evaluation audits; model/run/split comparison; uncertainty and robustness; and reproducibility handoffs.

The release never converts a learned graph prediction into an established relationship or evidence edge automatically.
