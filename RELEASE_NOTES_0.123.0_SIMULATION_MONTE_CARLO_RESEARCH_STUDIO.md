# Release Notes — Lab v0.123.0

**Simulation & Monte Carlo Research Studio** adds a reproducible research-facing simulation layer to Sustainable Catalyst Lab.

Highlights include Monte Carlo, Latin-hypercube, Sobol and Saltelli-Sobol designs; explicit seeds and compute budgets; uncertainty propagation; convergence checkpoint reports; seed-replication diagnostics; parameter sweeps; scenario ensembles; threshold-probability reports; publication visualization plans; snapshots/reproduction/export plans; and reference-first Platform Core handoffs.

The release preserves a strict semantic boundary between simulation and observation. Modeled results are never automatically promoted to evidence, and the Studio does not automatically certify convergence, rank scenarios, infer causality, certify scientific validity, or mutate Platform Core.
