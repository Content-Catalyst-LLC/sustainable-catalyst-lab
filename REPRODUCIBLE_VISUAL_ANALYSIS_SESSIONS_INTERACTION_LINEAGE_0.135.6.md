# Lab v0.135.6 — Reproducible Visual Analysis Sessions & Interaction Lineage

v0.135.6 records the visual-analysis workflow as a governed, replayable sequence of presentation and reference-state events. Sessions can preserve scene focus, drill paths, comparisons, pins, filters, camera/viewport state, annotations, layouts and checkpoints while retaining explicit references to the underlying scientific objects.

The interaction lineage is a workflow record, not scientific evidence. Event order does not imply causality; replay does not certify scientific replication; and presentation state never mutates the scientific record. Platform Core handoff remains explicit and reference-first.
