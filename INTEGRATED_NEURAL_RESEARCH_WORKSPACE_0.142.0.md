## Shared workspace contracts
- One session/project/study/experiment context.
- Shared object index and provenance references.
- Focused and pinned objects propagate context across panels.
- Dependency/lineage graph remains explicit.
- Readiness, missingness, review state, limitations, and provenance remain visible.
- Deterministic workspace snapshots and diffs support reproducible review.
- Handoffs target Workspace execution, Platform Core canonical objects, Research OS lifecycle, the v0.141.8 reproducibility package, and publication workflows.

## Scientific boundaries
Integration is coordination, not validation. Prediction is not evidence; embedding proximity is not a relationship; explanation is not causal proof; ablation delta is not a causal effect; optimization extrema are not scientific winners; package completeness is not scientific validity; review completion is not publication acceptance.
