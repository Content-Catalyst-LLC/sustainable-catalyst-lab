# Release Notes — Lab v0.135.2

Sustainable Catalyst Lab v0.135.2 adds interactive Model Architecture & Computational Provenance Graphs to the v0.135.1 Scientific Visualization Experience. Graph Studio can now expose data → transformation → model → execution → uncertainty → figure → evidence → Platform Core relationships as an interactive research graph with explicit bound, declared, derived, unbound, and external states.

The backend adds governed graph normalization, lineage and path traversal, dependency views, cycle/orphan audits, deterministic layouts, diagnostic/assumption/evidence overlays, snapshots, exports, and reference-first Core plans. No scientific values or undeclared internals are fabricated.
