# Deploy Lab Backend v0.135.5

From the extracted v0.135.5 release directory on macOS, copy the backend ZIP and versioned deployment script to the Contabo host, SSH to the host, and execute the deployment script.

The deployment verifies the retained v0.135.2 provenance graph, v0.135.3 multi-view canvas, v0.135.4 interactive scene/drill-down, and the v0.135.5 scene-linking/comparative-context health contract. It also checks Platform Core >= 3.0.0 compatibility when the Core health endpoint is reachable.
