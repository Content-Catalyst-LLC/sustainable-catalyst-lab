# Deploy Lab backend v0.135.8.5.2

From macOS, upload the backend archive and deployer to Contabo, then run the deployer. The deployer preserves `.env.production`, backs up the live backend, rebuilds/restarts the `lab` service, verifies v0.135.8.5.2 incremental-interaction routes, verifies the retained native provenance and Renderer 3.1 contracts, and checks Platform Core v3 compatibility.
