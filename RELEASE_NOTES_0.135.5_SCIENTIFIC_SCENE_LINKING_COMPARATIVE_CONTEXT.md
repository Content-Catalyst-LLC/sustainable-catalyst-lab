# Release Notes — Lab v0.135.5

Sustainable Catalyst Lab v0.135.5 adds Scientific Scene Linking, Comparative Inspection & Context Preservation to the visualization sequence. It links the v0.135.4 drill-down scene with the v0.135.3 analysis canvas so researchers can pin explicit references, compare declared peers, preserve inspection context, and carry provenance/uncertainty/evidence/spatial-temporal context across views.

The backend adds governed reference links, context capsules, comparison sets, mapping/equivalence guards, context diffs and snapshots, export/handoff plans, and reference-first Platform Core plans. Presentation/context state never mutates scientific objects and the Lab does not infer equivalence, joins, causality, evidence weight, validity, truth, or Core submission.
