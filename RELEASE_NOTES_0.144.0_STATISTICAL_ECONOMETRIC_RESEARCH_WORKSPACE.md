# Release Notes — Lab v0.144.0

**Statistical & Econometric Research Workspace**

This release adds a unified governed workspace for statistical and econometric research. It introduces explicit estimand, model-specification, estimate-result and diagnostic objects; panel/time-series and IV/identification audits; robust inference and comparison matrices; uncertainty, sensitivity, visualization, export and reproducibility handoffs.

Workspace remains responsible for numerical estimation. Platform Core remains canonical governed-object authority. Lab does not infer causation from association, treat statistical significance as substantive importance, certify assumptions from diagnostic tests, automatically rank models, or equate reproducibility with scientific validity.
