# Release Notes — Lab v0.118.0

## Visual Research Narrative & Figure Composer

This release adds publication-oriented visual storytelling while retaining scientific provenance and artifact authority.

### Added

- Reference-first research narrative object model.
- Immutable figure registry for statistical figures, dashboards, small multiples, maps, diagrams, model views, uncertainty views, and 3D/4D scenes.
- Multi-panel figure plates with deterministic panel order and labels.
- Declared caption packages and source/method/finding/evidence/citation notes.
- Evidence-aware annotation layers without automatic evidence weighting.
- Methods/findings/evidence/citation link bundles.
- Narrative-wide provenance trace.
- Journal/report/poster/slide/web layout plans.
- Publication/export plans and publication packages.
- Deterministic revision snapshots.
- Accessibility audit for captions and alt text.
- Platform Core visual-binding plan for narrative identity and provenance.
- WordPress health/catalog/schema surface and narrative presentation styles.

### Boundaries

No automatic conclusion generation, figure mutation, caption inference, relationship inference, evidence weighting, publication approval, Core submission, scientific validity certification, or truth determination.
