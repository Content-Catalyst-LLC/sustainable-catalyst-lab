# Deploy Lab backend v0.135.1

Upload `sustainable-catalyst-lab-backend-v0.135.1.zip` and `upgrade_lab_backend_v0_135_1_contabo.sh` to `/tmp` on the Lab VPS, then execute the upgrade script. The script preserves compose-managed data, normalizes extracted ZIP permissions, verifies v0.135.0 retention, checks Platform Core >= 3.0.0, and exercises the v0.135.1 visualization-experience contract.
