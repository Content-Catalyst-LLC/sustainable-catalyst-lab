# Release Notes — Lab v0.132.0

## Method Selection Intelligence

This release begins the second scientific-intelligence capability after v0.131.0. It connects research-question/hypothesis objects to appropriate candidate methods while preserving methodological alternatives and researcher authority.

Highlights include transparent eligibility reasoning, a 20-method built-in catalog spanning the major Lab analysis environments, explicit requirement and assumption gaps, cross-method comparison without ranking, diagnostic/validation/sensitivity planning, deterministic decision provenance, and reference-first Core handoffs.

The release intentionally does not implement automatic method ranking or scientific validity certification.
