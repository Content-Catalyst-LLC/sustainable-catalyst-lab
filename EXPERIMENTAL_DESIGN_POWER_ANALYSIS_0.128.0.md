# Lab v0.128.0 — Experimental Design & Power Analysis

A governed design-planning layer for Sustainable Catalyst Lab. It provides analytical and simulation-based power planning, factorial/block/cluster design structures, precision planning, deterministic randomization schedules, sequential/adaptive planning objects, multiplicity plans, diagnostics, visualization plans, reproducible snapshots, and reference-first Platform Core handoffs.

## Scientific boundaries
Power is conditional on declared assumptions and is never a guarantee. The Studio does not infer a scientifically meaningful effect size, certify randomization concealment, select a design automatically, label results significant, certify ethics/scientific validity, or submit findings automatically to Platform Core.
