# Lab v0.134.0 Release Notes — Evidence Synthesis Intelligence II

Sustainable Catalyst Lab v0.134.0 begins the cross-study synthesis portion of the Scientific Intelligence roadmap.

This release adds a 44-route governed API for evidence synthesis, integrating quantitative meta-analysis, qualitative/mixed-method planning, contradictions, heterogeneity, replication disagreement, uncertainty, claim/hypothesis maps, assumption/diagnostic references, provenance, lineage, researcher adjudication, visualization, deterministic snapshots, and Platform Core reference plans.

The existing v0.64 systematic evidence synthesis numerical engine is retained and reused for fixed/random-effects pooling. v0.134 does not replace it with a duplicate statistical implementation; it adds the broader scientific-intelligence layer around it.

Release validation: 465 retained integration/regression tests plus release-specific route, contract, WordPress, manifest, clean-source, and standalone-backend checks.
