# Release Notes — Lab v0.163.0

Adds Institutional Research Governance & Review Federation above v0.162.0. The release introduces explicit institutions, governance bodies, federated review relationships, reviewer assignments with independence declarations, human decisions/dissent, attestations, review-case transitions, governance command center, snapshots, manifests, WordPress proxy/UI integration, and persistent backend state.

Scientific validity and consequential governance decisions remain human-controlled.
