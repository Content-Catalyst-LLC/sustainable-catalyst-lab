# Sustainable Catalyst Lab v0.162.0 — Cross-Project Dependency & Research Resource Planning

This release extends v0.161.0 Research Program & Portfolio Orchestration with explicit cross-project dependency and shared-resource planning. It records project-to-project dependencies, shared research resources, project requirements, descriptive capacity conflicts, human-authored planning scenarios, program planning command centers, immutable snapshots, timelines, and digest-verifiable manifests.

## Authority boundaries

- Platform Core remains canonical object authority.
- Workspace remains execution authority and performs compute/scheduling work when explicitly handed off.
- Research OS v0.160.0 remains project lifecycle authority.
- v0.161.0 remains research-program and portfolio authority.
- v0.162.0 plans and describes dependencies/resources; it does not optimize or allocate them automatically.

## Safety/governance

No automatic dependency inference, project ranking, funding allocation, resource allocation, scheduling, execution, scientific-validity judgment, replication judgment, or publication. Plan approval and snapshot freezing require explicit human authorization.
