# Release Notes — Lab v0.149.0

Adds the Scientific Model Validation & Benchmark Laboratory on the v0.148.0 multimodal foundation. Introduces governed benchmark suites/cases, reference standards, model submissions, evaluation runs, validation records, leakage/split/reference audits, calibration/generalization/robustness/domain-shift/subgroup analysis, failure taxonomies, external validation, benchmark/baseline matrices, linked visual specifications, cross-product handoffs, deterministic snapshots, export bundles, and reproducibility packages.

Epistemic rule: benchmark score, external validation, robustness, calibration, or agreement with a reference standard does not automatically establish scientific validity, universal validity, causal adequacy, or deployment readiness.
