# SC-FIG-03A — MapLibre adapter preparation

**State:** prepared in 0.163.1.7. Since 0.163.1.8 the contract is loaded and drawn by SC-FIG-04
(behind its own switch, default off): see [SC-FIG-04 geospatial figures](SC-FIG-04_GEOSPATIAL_FIGURES.md).
View 1.0 behaviour is unchanged.

## Contract

A map view (`application/vnd.sc.maplibre-view.v1+json`, schema `sc-lab-maplibre-view/1.0`) carries
Site Intelligence spatial evidence objects (`sc-site-intelligence-spatial-evidence-object/2.0`) as
SI's `normalize_evidence_object` produced them. Lab does not redefine spatial data or provenance.

| Rule | Check |
|---|---|
| SI identity | Each `content_digest` is recomputed from the file's own text (canonical JSON, number spellings kept) and must match. |
| CRS | `crs` must be `EPSG:4326`. If the source CRS differs, SI must have recorded the transformation. Lab never reprojects. |
| Geometry | Point, line and polygon types only, in WGS84 range, with the bbox SI derived. RasterFootprint is refused (it needs tiles). |
| Network | No basemap, tile template, glyphs, sprite or URL. The provider allow-list is empty until a provider has approved provenance. |
| Style | Constant colours, widths and opacities per layer. Author-supplied MapLibre expressions are refused. A layer filter may select one evidence class only. |
| Evidence | Every object has an evidence class. Objects are observed only in an observed figure. Mixed classes are drawn by separate layers, and every layer has a legend label. |
| Bundle | `figureType` is `spatial-map`, `spatial.crs` is `EPSG:4326`, and the bbox covers every object. Every SI source is cited. `source-verified` geometry needs hash-verified sources. |
| Visibility | Only `public` SI objects. Private objects need the Workspace path. |

`compileStyle` produces a MapLibre style v8 with a single inline GeoJSON source and no external
references. `tableModel` lists every object with its units, time, source, licence and SI digest.

## Tests

`node tests/test-maplibre-fig03a.js` covers the synthetic view (2 modelled zones and 2 literature
sites), the compiled style and the table, plus 21 refusals. Fixtures are generated by
`tests/fixtures/fig03a-maplibre/build_fixtures.py <site-intelligence checkout>`, which runs SI's
normaliser and records the SI commit.
