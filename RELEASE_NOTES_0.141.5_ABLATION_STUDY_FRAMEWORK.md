# Release Notes — Lab v0.141.5

**Ablation Study Framework** adds controlled baseline/variant study definitions, Workspace execution handoffs, comparability and confounding audits, paired metric deltas, component-effect summaries, replicate summaries, interaction guardrails, review-only candidate sets, visual specifications, Platform Core handoff, deterministic snapshots, export bundles, and reproducibility packages.

Execution remains in Workspace. Lab never treats ablation deltas as automatically causal and does not select or promote a winning model.
