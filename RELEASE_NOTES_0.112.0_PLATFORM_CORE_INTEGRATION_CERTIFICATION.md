# Sustainable Catalyst Lab v0.112.0 — Platform Core Integration Certification

Lab v0.112.0 closes the v0.104–v0.111 Platform Core integration sequence with a governed conformance-certification bridge aligned to Platform Core's `sc.research.platform-integration-certification.v1` contract.

## What it certifies

The release defines eight integration layers and eighteen required conformance cases covering runtime adaptation, canonical research objects, project/session context, execution lineage, findings/claims/evidence/validation, visual reasoning/scientific scenes, reproducibility/scholarly packages, and scientific investigations.

Certification is intentionally limited to **platform runtime-contract conformance evidence**. It does not certify scientific validity, product quality, reproducibility as a scientific conclusion, authorization, evidence ranking, hypothesis selection, causality, or truth.

## Core integration operations

The bridge can construct explicit, non-submitting plans for Core certification suites, product registration, conformance cases, runs, case results, exchange checks, trace checks, reproduction checks, certification evidence, certification findings, snapshots, and full end-to-end certification sequencing.

It can also assess caller-supplied declared case results locally and check Core certification readiness/boundaries. It does not invoke the Lab product or execute conformance cases automatically.

## Compatibility

Minimum Platform Core release: **3.0.0**. Newer compatible 3.x releases are accepted when the required certification registries and non-authority boundaries remain present.
