# Lab v0.135.2 — Model Architecture & Computational Provenance Graphs

v0.135.2 exposes Sustainable Catalyst's scientific computation as interactive, reference-first research graphs. It adds 20 governed node types, 18 declared edge types, architecture/provenance/execution/evidence views, path traversal, upstream/downstream analysis, structural-impact paths, cycle/orphan audits, deterministic layered/swimlane/radial layouts, overlays, snapshots, exports, and Platform Core plans.

Graph Studio now renders an interactive under-the-hood graph from declared or currently bound objects. Missing scientific internals are represented as unbound rather than inferred. Graph navigation and layout are presentation state and never mutate the scientific record.

Scientific boundaries: no fabricated scientific values; no undeclared model/provenance inference; structural downstream impact is not causal impact; no evidence weighting, claim-status changes, scientific-validity certification, truth determination, or automatic Core submission.
