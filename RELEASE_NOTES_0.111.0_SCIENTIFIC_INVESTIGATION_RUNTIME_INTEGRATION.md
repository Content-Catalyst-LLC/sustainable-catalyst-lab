# Sustainable Catalyst Lab v0.111.0 — Scientific Investigation Runtime Integration

Lab v0.111.0 binds governed scientific investigations into Platform Core v3's unified research/scientific/investigation runtime. The bridge records investigation identity, explicit evidence/claim/hypothesis references, and references to datasets, models, experiments, analyses, executions, visuals, validations, packages, protocols, methods, and sources.

The release is reference-first. Lab remains authoritative for scientific work and artifacts. Core does not run investigations, infer findings, rank evidence, resolve contradictions, select hypotheses, infer causality, certify scientific validity, or determine truth.

## Integration surfaces

- canonical scientific-investigation normalization
- Core unified-runtime investigation binding envelopes
- evidence/source context bridge
- claim/hypothesis/reasoning context bridge
- scientific asset reference bridge
- runtime integration planning across existing v0.105-v0.110 bindings
- project/session investigation continuity checks
- legacy v0.61 scientific-study mapping
- legacy v0.66 scientific-argumentation mapping

## Platform Core compatibility

Minimum compatible Platform Core release: **3.0.0**. Newer compatible v3 releases are accepted.
