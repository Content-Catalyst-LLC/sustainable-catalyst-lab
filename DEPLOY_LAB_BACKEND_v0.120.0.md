# Deploy Lab backend v0.120.0

Upload `sustainable-catalyst-lab-backend-v0.120.0.zip` and `upgrade_lab_backend_v0_120_0_contabo.sh` to `/tmp` on the Lab VPS, then run the upgrade script. The verifier checks v0.114–v0.119 visualization health, v0.120 EDA health, required v0.120 behavior, and Platform Core >= 3.0.0. Application-wide route totals are informational only.
