# Lab v0.126.0 Release Notes

**Spatial & Spatiotemporal Research Studio** adds reproducible spatial weights, Moran/local-Moran/Getis-Ord diagnostics, nearest-neighbor and descriptive spatial-lag workflows, raster zonal/change analysis, space-time cubes, temporal profiles, trajectories, hotspot persistence, visualization/export/reproduction plans, and Platform Core reference plans.

Spatial association remains non-causal. CRS, units, weights, time semantics, and raster alignment remain explicit; no silent reprojection, significance labeling, causal inference, scientific-validity certification, or Core submission is performed.
