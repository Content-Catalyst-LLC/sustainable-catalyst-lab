# Release Notes — Lab v0.135.3

Sustainable Catalyst Lab v0.135.3 adds the Multi-View Scientific Analysis Canvas to the v0.135.2 model-architecture and computational-provenance graph experience. Graph Studio can now coordinate figures, diagnostics, uncertainty, evidence, provenance, model graphs, tables, annotations, and narrative context through explicit linked selections, filters, synchronized domains/cursors, brushing, and focus state.

The backend adds governed canvas normalization, five deterministic layouts, ten panel types, eight interaction channels, explicit mapping requirements, non-mutating filter evaluation, snapshots, exports, handoffs, and reference-first Platform Core plans. Presentation state never changes scientific values or canonical research objects, and no join, validity, evidence, probability, truth, or Core-submission decision is inferred automatically.
