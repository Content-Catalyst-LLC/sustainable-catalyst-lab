# Sustainable Catalyst Lab v0.110.0 — Reproducibility & Scholarly Package Bridge

Lab v0.110.0 links Lab reproducibility and scholarly artifacts to Platform Core v3 package and scholarly-interoperability contracts. Lab remains authoritative for the scientific package, artifact bytes, execution evidence, manuscripts, figures, and publication objects. Core records references and declared interoperability metadata.

## Added

- Reference-first Core unified-runtime `package-bindings`.
- Core scholarly-package creation envelopes and ordered interoperability plans.
- Citation metadata, dataset/notebook descriptors, provenance manifests, publication bindings, and declared validation records.
- Legacy mappings for Lab reproducibility/publication/manuscript/model-package schemas.
- WordPress health/manifest/schema discovery surface.

## Boundaries

Core does not mint/register identifiers, publish/submit packages, resolve citations, execute notebooks, transform datasets, certify reproducibility, validate scientific content, infer authorship, or determine truth. The bridge never auto-submits or auto-mutates Core.
