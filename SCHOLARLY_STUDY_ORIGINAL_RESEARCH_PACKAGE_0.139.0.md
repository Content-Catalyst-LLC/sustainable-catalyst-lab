# Lab v0.139.0 — Scholarly Study & Original Research Package

v0.139.0 turns a Lab study into a deterministic, reviewable original-research package without changing the authority of the underlying scientific objects.

## Package contents

- research question and hypotheses
- declared methods and datasets
- executions, models, analyses, simulations, figures, and tables
- claims, evidence, and findings
- limitations and interpretation boundaries
- review records and reproduction packages
- manuscripts, citations, contributors, and identifiers
- provenance and immutable package/snapshot fingerprints
- v0.137.0 living-analysis state when supplied
- v0.138.0 research-program context when supplied

## Architecture

The package is an assembly and exchange layer. Source datasets, models, runs, claims, findings, review records, and provenance remain authoritative in their source systems. The release exposes a Core scholarly handoff plan but does not submit automatically.

## Scientific boundary

Package completeness or reproducibility is not scientific correctness. Review completion is not peer-review acceptance. Readiness is descriptive and does not confer scientific validity, causal truth, evidentiary weight, publication acceptance, or identifier registration.
