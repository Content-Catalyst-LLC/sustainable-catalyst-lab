# Sustainable Catalyst Lab v0.135.18.0
## Multi-Reviewer Panels, Independent Sign-Off & Dissent

v0.135.18.0 extends the Graph Studio scientific review line with governed multi-reviewer panels.

### Added
- first-class multi-reviewer panel records
- reviewer roles, optional conflict disclosures, and user-attested independence
- independent assessment lineage
- reviewer-specific sign-off states: signed, withheld, abstained
- first-class dissent records and alternative interpretations
- per-reviewer panel matrix with no majority winner or consensus score
- administrative completion tracking that remains separate from scientific resolution
- append-only review-audit event drafts
- Project Workspace panel context handoff
- backend normalization, validation, fingerprints, panel packets, status, contracts, and acceptance checks

### Governance
This release deliberately does not implement majority voting, consensus scoring, reviewer ranking, automatic review resolution, automatic scientific validity, automatic claim confirmation, evidence-weight inference, causal inference, or truth ranking.

### Compatibility
The release is additive and backward-compatible with v0.135.17.0 review-to-reproduction bridges, v0.135.16.0 revision-impact analysis, v0.135.15.0 verification evidence bundles, and the v0.135.14.0 append-only review audit.
