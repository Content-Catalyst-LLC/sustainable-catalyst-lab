# Lab v0.135.4 — Interactive Scientific Scene & Visual Drill-Down

v0.135.4 turns the coordinated v0.135.3 analysis canvas into an inspectable scientific scene. Researchers can drill from a figure or scene layer into explicitly referenced rows, objects, model components, uncertainty objects, diagnostics, evidence, provenance nodes, spatial/temporal frames, volumes, and trajectories while retaining the source scientific objects as authoritative.

The runtime defines 12 governed scene-layer types, 8 drill-target types, 6 view modes, 5 navigation modes, and 4 level-of-detail modes. Camera, viewport, visual isolation, slice position, drill breadcrumbs, and LOD are presentation state. Cross-layer mappings and parent/child drill paths are explicit and reference-first.

Scientific boundaries: no inferred hierarchy, joins, CRS transformation, temporal interpolation, probability interpretation, evidence weighting, claim-status mutation, scientific-validity certification, truth determination, or automatic Platform Core submission. Structural trace paths are not causal-effect estimates.
