# Lab v0.135.8.5 — Native Provenance State Engine, Interactive Graph Runtime & Browser Hardening

Replaces the DOM-patch provenance interaction layer with a first-class graph model/controller. Selection, traversal, layout, relation filtering, inspector context, zoom state, and project presentation-state persistence now originate in graph state and are rendered into Renderer 3.1. MutationObserver is not an interaction owner. Structural provenance is never promoted to causal meaning and missing relationships are not inferred.
