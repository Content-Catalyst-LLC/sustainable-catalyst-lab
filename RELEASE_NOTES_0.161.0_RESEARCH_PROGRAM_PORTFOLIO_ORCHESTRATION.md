# Release notes — Lab v0.161.0

**Research Program & Portfolio Orchestration**

v0.161.0 adds governed multi-project research programs and multi-program portfolios above the v0.160.0 Research OS lifecycle.

Highlights:

- Research program and portfolio registries
- Reference-first Research OS project membership
- Program roles and workstreams
- Objectives, milestones, and project-to-objective allocation
- Human-controlled program and portfolio state machines
- Descriptive command-center aggregation
- Immutable snapshots and digest-verifiable manifests
- WordPress HMAC proxy and authenticated front-door integration
- Persistent backend database and deployment configuration

Guardrails remain explicit: the system does not rank projects, allocate funding/resources, execute research automatically, infer scientific validity, or publish automatically. Program/portfolio completion is procedural state, not a claim that underlying science is valid.
