# Release notes — Lab v0.135.1

**Scientific Visualization Experience Overhaul**

This visual-first release upgrades Graph Studio with a multi-panel scientific analysis canvas, data-aware empirical/residual previews, model and provenance graphics, capability-state visualization, evidence context, full-screen analysis, and explicit figure/analysis/under-the-hood/evidence modes.

No scientific values are invented to populate the interface. Missing governed scientific objects remain visibly unlinked. The existing scientific figure, scene, uncertainty, spatial, provenance, and renderer contracts remain authoritative.
