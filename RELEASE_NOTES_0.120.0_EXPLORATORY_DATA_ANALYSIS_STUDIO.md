# Sustainable Catalyst Lab v0.120.0 — Exploratory Data Analysis Studio

Lab v0.120.0 adds a reproducible exploratory-data-analysis layer over the scientific data and visualization stack. It provides dataset profiling, missingness structure, distributions, Pearson/Spearman association summaries, descriptive group comparisons, robust outlier flags, pairwise relationship summaries, explicit transformation planning/preview, PCA exploration, publication-aware visualization plans, deterministic snapshots, export plans, and reference-first Platform Core artifact plans.

The release explicitly separates exploration from confirmation: it does not automatically mutate source data, drop outliers, confirm hypotheses, make significance claims, infer causality, infer MCAR/MAR/MNAR mechanisms, certify scientific validity, submit to Platform Core, or determine truth.
