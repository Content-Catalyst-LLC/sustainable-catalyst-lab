# Deploy Lab backend v0.135.8.2

Copy `sustainable-catalyst-lab-backend-v0.135.8.2.zip` and `upgrade_lab_backend_v0_135_8_2_contabo.sh` to `/tmp` on the Contabo VPS, then run the upgrade script. The verifier requires the complete retained v0.135.2–v0.135.8.1 visual-research stack, 24 v0.135.8.2 renderer routes, one primary renderer owner, legacy Graph Studio execution disabled, and compatible Platform Core v3+.
