# Lab v0.158.0 — Scientific Reproduction & Independent Replication Network

Adds a governed network layer above v0.157.0 cross-study synthesis. The release records independent replication nodes, declared independence evidence, immutable preregistered replication plans, explicit Workspace execution handoffs, result receipts, deviations, human review records, network coverage and digest-verifiable manifests.

Scientific boundary: independence is declared rather than inferred. The network does not execute replications automatically, label findings confirmed/refuted, infer causality, or establish scientific validity. Human review remains required.
