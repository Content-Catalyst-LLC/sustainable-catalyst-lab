# Release Notes — Lab v0.152.0

Cross-Workspace Research Dependency Graph adds a governed research-object dependency and impact graph above the v0.151.0 orchestration layer. It exposes 120 backend routes and preserves the full v0.151.0 through v0.140.0 compatibility chain. Dependency edges remain descriptive lineage/dependency relations, never causal proof or evidence by default. Impact/staleness outputs require human scientific review and do not automatically invalidate, recompute, revalidate, retract, or advance research.
