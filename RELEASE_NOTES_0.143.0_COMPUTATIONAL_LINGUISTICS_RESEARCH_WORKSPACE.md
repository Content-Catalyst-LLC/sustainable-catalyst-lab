# Release Notes — Lab v0.143.0

**Computational Linguistics Research Workspace** introduces first-class governed linguistic research objects and reproducible corpus-analysis surfaces. Original-language text remains primary; translations, transliterations, OCR/HTR, transcriptions, tokenizations and annotations remain derived and provenance-bearing.

The release adds 48 FastAPI routes, WordPress runtime identity/health, browser workspace contracts, Workspace execution handoff, Knowledge Library source handoff, Platform Core canonical-object handoff, Research OS handoff, deterministic snapshots, export bundles and reproducibility packages.

Scientific guardrails explicitly prevent translation from replacing source text, alignment from becoming semantic equivalence, annotation from becoming ground truth, and cross-lingual similarity from becoming evidence.
