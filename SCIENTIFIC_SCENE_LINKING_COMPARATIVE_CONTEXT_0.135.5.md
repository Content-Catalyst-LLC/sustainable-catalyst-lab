# Lab v0.135.5 — Scientific Scene Linking, Comparative Inspection & Context Preservation

v0.135.5 coordinates the v0.135.3 multi-view analysis canvas and v0.135.4 interactive scientific scene. Researchers can pin an inspected reference, compare explicitly related objects, preserve drill/focus/navigation context, and move that context across canvas, scene, provenance, uncertainty, evidence, diagnostics, spatial, and temporal views.

The release defines 10 explicit link types, 6 comparison modes, 12 context families, 3 pin states, deterministic context capsules and snapshots, cross-scene linking plans, comparison guards, and reference-first Platform Core handoffs.

Scientific boundaries: comparison does not establish equivalence or causality; nonidentical objects are never treated as the same object unless equivalence is explicitly asserted; joins/mappings are not inferred; context capsules are non-authoritative presentation/reference state; evidence is not reweighted; claim status and scientific validity are not changed; truth is not determined; Platform Core submission remains explicit.
