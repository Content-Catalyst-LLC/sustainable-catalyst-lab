# Deploy Lab backend v0.107.0

From macOS, upload `sustainable-catalyst-lab-backend-v0.107.0.zip` and `upgrade_lab_backend_v0_107_0_contabo.sh` to `/tmp` on the Contabo VPS, SSH in, then run the upgrade script.

The verifier accepts Platform Core >=3.0.0, validates retained v0.104-v0.106 integration health, validates the eight required v0.107 execution-lineage routes and contract behavior, and treats the global FastAPI path-route count as informational only.
