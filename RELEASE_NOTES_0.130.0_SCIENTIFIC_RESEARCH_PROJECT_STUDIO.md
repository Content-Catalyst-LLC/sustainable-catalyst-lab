# Release Notes — Lab v0.130.0

Scientific Research Project Studio is the integration milestone for research-project coordination. It creates a governed reference layer over the Lab's analytical, visualization, reproduction, publication and investigation capabilities and Platform Core's project/session/provenance contracts.

The release intentionally does not introduce a second authoritative object store. Domain artifacts remain owned by their source systems, while the Project Studio owns organization, declared relationships, workspace composition, snapshots, revision plans, and project-level handoffs.
