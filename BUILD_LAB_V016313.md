# Sustainable Catalyst Lab v0.163.1.3

## 4D Front-Door Visual Polish & Compact Control Layout

A presentation-only refinement of the v0.163.1.2 front door.

### Scope
- retain the live 4D visualization as the first substantive Lab surface;
- retain Scientific signals and the specialist workspace shell;
- keep Response Surface configuration immediately available;
- compact the 4D canvas and control spacing without reducing capability;
- make Uncertainty & sensitivity, Linked views & selection, Scene/provenance/handoff, and the server-backed Project 4D workspace progressive panels collapsed by default;
- preserve panel state for the browser session;
- present Peak response, W hyperslice, Field density and Layers as a compact instrument strip;
- reduce border/padding density while preserving the black/white/red Lab visual language.

No scientific compute method, persistence model, provenance rule, backend execution path, authorization rule, evidence interpretation, or publication behavior changes in this release.
