# Deploy Lab backend v0.152.0

Upload `sustainable-catalyst-lab-backend-v0.152.0.zip` and `DEPLOY_LAB_V01520_CONTABO.sh` to `/tmp`, then run the deployment script on the Contabo VPS. The script preserves the production environment, promotes the backend, rebuilds/restarts the Lab service, verifies v0.152.0 and predecessor health, and checks Platform Core reachability.
