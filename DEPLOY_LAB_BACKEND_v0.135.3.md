# Deploy Lab backend v0.135.3

Upload `sustainable-catalyst-lab-backend-v0.135.3.zip` and `upgrade_lab_backend_v0_135_3_contabo.sh` to `/tmp/` on the Contabo VPS, then execute the upgrade script. The deployer preserves the production environment, verifies retained v0.135.2 graph capability, rebuilds the Lab container, checks Platform Core compatibility, and exercises the new multi-view analysis canvas routes.
