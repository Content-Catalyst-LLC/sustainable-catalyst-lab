# Release Notes — Lab v0.128.0

## Experimental Design & Power Analysis

Adds explicit effect-size standardization, one-/two-sample and paired mean power, one-/two-proportion power, one-way ANOVA power, full-factorial allocation, blocked randomization, cluster design effects, precision-based sample size, seeded simulation-based power, sequential alpha-spending plans, adaptive re-estimation plans, multiplicity plans, deterministic randomization schedules, design diagnostics, publication visualization planning, snapshots, exports, lineage, and Platform Core reference plans.

No power calculation is represented as a guarantee and no design is automatically selected or certified.
