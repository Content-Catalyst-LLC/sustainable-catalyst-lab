# Sustainable Catalyst Lab v0.115.0
## Advanced Statistical & Uncertainty Graphics

v0.115.0 adds a publication-grade statistical graphics layer over the v0.114 Scientific Visualization Design System.

### Added
- 16 statistical/uncertainty figure families.
- Explicit-bandwidth Gaussian KDE for violin/raincloud/ridge views.
- Empirical histogram, ECDF and box summaries.
- Confidence/credible/prediction/bootstrap/custom interval ribbons.
- Nested quantile fan charts.
- Posterior interval and coefficient forest graphics.
- Calibration/reliability diagrams and descriptive ECE.
- Residual-vs-fitted diagnostics and declared-reference Q–Q graphics.
- Sobol, Morris, tornado and ranked-effect sensitivity graphics.
- Uncertainty decomposition and coverage graphics.
- Statistical small-multiple composition.
- v0.114 publication/export/accessibility bridge.

### Boundaries
Rendering and descriptive calculations do not automatically infer significance, causality, model quality, scientific validity, or truth. KDE bandwidth, interval semantics and Q–Q reference distributions are explicit inputs.
