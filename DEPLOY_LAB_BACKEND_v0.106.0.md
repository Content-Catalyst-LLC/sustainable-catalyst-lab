# Deploy Lab backend v0.106.0

From macOS, upload `sustainable-catalyst-lab-backend-v0.106.0.zip` and `upgrade_lab_backend_v0_106_0_contabo.sh` to `/tmp` on the Contabo VPS, SSH in, then run the upgrade script. The verifier accepts Platform Core >=3.0.0 and validates required v0.104-v0.106 routes/behavior without asserting a global FastAPI route total.
