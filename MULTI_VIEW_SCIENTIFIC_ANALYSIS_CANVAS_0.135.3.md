# Lab v0.135.3 — Multi-View Scientific Analysis Canvas

v0.135.3 turns Graph Studio into a coordinated scientific analysis surface. A single canvas can bind a primary figure, secondary figures, diagnostics, uncertainty, evidence, computational provenance, model architecture, tables, annotations, and narrative context while keeping every panel tied to explicit scientific-object references.

The release adds five deterministic layout modes, ten governed panel types, eight interaction channels, linked selections, explicit cross-panel mappings, shared filters, synchronized domains/cursors, brushing and focus plans, contextual evidence/diagnostic/uncertainty/provenance panels, deterministic snapshots, exports, handoffs, and reference-first Platform Core object plans.

Scientific boundaries: selections, filters, brushing, cursor state, focus, and layout are presentation state. Source data and canonical research objects are never rewritten. Nonidentical identifiers require explicit mapping references. The Lab does not infer joins, certify scientific validity, interpret probabilities automatically, weight evidence automatically, change claim status, determine truth, or submit objects to Platform Core automatically.
