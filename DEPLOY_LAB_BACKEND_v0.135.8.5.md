# Deploy Lab backend v0.135.8.5

Upload `sustainable-catalyst-lab-backend-v0.135.8.5.zip` and `upgrade_lab_backend_v0_135_8_5_contabo.sh` to `/tmp`, then execute the deployer with the ZIP path. The deployer backs up the live backend and environment, rebuilds `sc-lab`, verifies the 13 native-provenance routes, retained Renderer 3.1 recovery, and Platform Core compatibility.
