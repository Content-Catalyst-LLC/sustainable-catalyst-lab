# Deploy Lab backend v0.135.9.0

Upload `sustainable-catalyst-lab-backend-v0.135.9.0.zip` and `upgrade_lab_backend_v0_135_9_0_contabo.sh` to `/tmp`, then run the deployer with the backend ZIP path. The deployer preserves `.env.production`, validates the new Scientific Object Explorer routes, the retained native provenance controller, Renderer 3.1 recovery, and Platform Core compatibility.
