# Release Notes — Lab v0.135.19.0

## Cross-Review Synthesis & Resolution Matrix
Adds a project-level synthesis layer over the v0.135.12–v0.135.18 review lineage. Review threads can now be inspected together with their revision actions, verification bundles, reproduction bridges, impact analyses, reviewer panels, dissent, and audit history.

### Added
- Cross-review synthesis object and project collection
- Resolution matrix and administratively-open register
- Dissent/disagreement register
- Verification, reproduction, and revision-impact matrices
- Resolution history and subject index
- Snapshot/compare workflow
- Project Workspace packet and handoff
- 21 FastAPI routes

### Guardrails
No majority voting, consensus scoring, reviewer ranking, truth ranking, causal inference, evidence-weight inference, scientific preference, or automatic scientific resolution.
