# Release Notes — Lab v0.135.8.2

**Graph Studio Renderer Replacement & Advanced Visual Analysis Workspace**

This repair replaces the simplistic legacy Graph Studio canvas as the primary renderer. Graph Studio now owns a dedicated Renderer 3.0 workspace with Plot, Distribution, Diagnostics, Uncertainty, Provenance and 3D/Spatial modes, an object inspector, interactive provenance layouts, bound-row drill-down and explicit renderer lifecycle ownership.

Historical Graph Studio v0.79–v0.88 files remain available for compatibility/import support but no longer execute on the canonical Graph Studio route. Existing v0.135.1–v0.135.8 research capabilities remain reference-first and scientifically non-mutating.
