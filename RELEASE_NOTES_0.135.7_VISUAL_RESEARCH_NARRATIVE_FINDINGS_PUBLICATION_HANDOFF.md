# Release Notes — Lab v0.135.7

Sustainable Catalyst Lab v0.135.7 adds Visual Research Narrative, Findings & Publication Handoff on top of the reproducible visual-analysis session stack.

The release provides governed narrative blocks, explicitly declared finding states, citation binding, publication outlines and packages, deterministic reference manifests, and explicit handoff plans to Platform Core, Publication Studio, Knowledge Library and Workspace. Presentation choices never become scientific claims or evidence automatically.
