# Lab v0.163.1.3 — 4D Front-Door Visual Polish & Compact Control Layout

This release refines the established 4D-first Lab front door without restructuring the product.

The response surface remains open and immediately interactive. Advanced controls are still present but open progressively so the front door does not extend as far down the page on first load. The visual canvas is modestly shorter, field spacing is tighter, secondary borders are quieter, and headline metrics are consolidated into a compact instrument strip.

Scientific signals remain visible. The v0.163.1.2 specialist shell remains below the front door and continues to expose one specialist workspace at a time.

This release is presentation-only. It does not alter scientific calculation, model execution, evidence semantics, provenance, storage, authentication, governance, or publication behavior.
