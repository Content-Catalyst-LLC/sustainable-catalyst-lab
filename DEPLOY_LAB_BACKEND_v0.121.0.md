# Deploy Lab backend v0.121.0

From macOS, upload `sustainable-catalyst-lab-backend-v0.121.0.zip` and `upgrade_lab_backend_v0_121_0_contabo.sh` to `/tmp`, SSH to the VPS, then run the upgrade script. The verifier checks v0.120 EDA, v0.121 statistical modeling/diagnostics, retained visualization health, and Platform Core >= 3.0.0. Application-wide route count is informational only.
