
# Lab v0.138.0 — Cross-Study Research Program Intelligence

This release elevates living analysis from a single research project to a declared research program containing multiple related studies.

## Integrated model
research program → study registry → declared study relationships → shared research objects → cross-study change propagation → study-level re-review/rerun assessment obligations → program living status → snapshots and Project Workspace handoff

## Scientific boundary
Program intelligence is organizational and dependency-aware. Cross-study agreement is not automatically treated as consensus, replication success, truth, causal validity, or stronger evidence. Human scientific judgment remains required.
