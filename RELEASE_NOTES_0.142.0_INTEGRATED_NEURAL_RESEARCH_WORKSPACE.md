# Release Notes — Lab v0.142.0

## Integrated Neural Research Workspace
This milestone consolidates Lab v0.141.0–v0.141.8 into a linked nine-panel neural research workspace with shared session state, object focus, lineage, provenance, review context, reproducibility state, and governed handoffs.

### Added
- Shared integrated neural session contract and object index.
- Nine linked panels spanning experiment design through reproducibility.
- Cross-panel object focus and linked-view context.
- Lineage graph, provenance summary, readiness and missingness reporting.
- Review packet, deterministic workspace snapshots/diffs, and export bundles.
- Workspace, Platform Core, Research OS, reproducibility-package, and publication handoffs.

### Boundaries
Workspace continues to execute compute. Platform Core continues to own canonical governed objects. Lab coordinates and interprets. Integration does not certify scientific validity, promote models, infer causation, or convert predictions/embeddings/explanations into evidence.
