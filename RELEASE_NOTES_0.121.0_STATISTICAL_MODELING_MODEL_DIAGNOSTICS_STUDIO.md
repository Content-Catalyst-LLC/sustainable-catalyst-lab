# Release notes — Lab v0.121.0

**Statistical Modeling & Model Diagnostics Studio**

- Adds Gaussian, robust, regularized, binomial-logit, and Poisson-log model workflows.
- Adds coefficient and effect-scale reports without automatic significance labels.
- Adds residual, normality, heteroskedasticity, independence, VIF, influence/Cook's distance, calibration/classification, deviance, and dispersion diagnostics.
- Adds explicit prediction evaluation and repeated k-fold cross-validation.
- Adds side-by-side model comparison with preserved candidate order and no automatic winner.
- Adds publication-aware visual plans, reproducible snapshots, export plans, and reference-first Platform Core object plans.
- Preserves source-data immutability and separates statistical diagnostics from scientific/causal conclusions.
