# Release notes — Lab v0.141.8 Reproducible Neural Research Package

Lab v0.141.8 completes the first neural-research packaging milestone by consolidating the v0.141.0–v0.141.7 lineage into a governed, deterministic research package.

The release adds package manifests and component registries, section inventories, dependency/checksum/lineage/environment/seed audits, neural-release-chain audits, descriptive completeness and missingness reports, reproduction instructions, Workspace rerun handoffs, rerun plans, verification checklists, evidence-boundary audits, export manifests, Platform Core handoffs, Scientific Research OS handoffs, publication handoffs, deterministic snapshots, package diffs, and final reproducibility packages.

Scientific guardrails remain explicit. A complete package does not establish scientific validity. A rerun is not automatically an independent replication. Hash declaration is not artifact verification. Environment or seed matching does not guarantee bitwise reproduction. Publication handoff is not publication acceptance.

The v0.140.0.1 installed-runtime integrity policy is retained, and all neural predecessor routes from v0.141.0 through v0.141.7 remain available.
