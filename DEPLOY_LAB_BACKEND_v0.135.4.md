# Deploy Lab Backend v0.135.4

From the extracted v0.135.4 release directory on macOS, copy the backend ZIP and deployment script to the Contabo host, SSH to the host, and execute the versioned deployment script.

The deployment retains and verifies v0.135.2 computational provenance graphs and v0.135.3 multi-view canvas health, then verifies the v0.135.4 interactive scene/drill-down health contract and Platform Core >= 3.0.0 compatibility.
