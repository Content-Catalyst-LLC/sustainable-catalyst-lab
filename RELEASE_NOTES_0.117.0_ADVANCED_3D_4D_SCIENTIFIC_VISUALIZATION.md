# Sustainable Catalyst Lab v0.117.0 — Advanced 3D/4D Scientific Visualization

This release extends the Lab visualization stack with explicit scientific 3D/4D semantics: surfaces, topology-preserving meshes, vector/scalar fields, volume plans, trajectories, temporal frames, slicing, isosurfaces, uncertainty geometry, camera provenance, renderer plans, publication exports, dashboard panels, and Core visual bindings.

No geometry, topology, transfer function, isovalue, time axis, uncertainty semantics, scientific validity, or truth is inferred automatically.
