# Sustainable Catalyst Lab v0.122.0

**Bayesian Analysis Workbench II** adds a research-facing Bayesian workflow above the retained v0.52 sampler. It introduces prior/posterior review, convergence diagnostics, posterior predictive checks, posterior probability queries, a new normal-normal hierarchical Bayesian random-effects engine, non-ranking model comparison, publication visualization plans, deterministic snapshots, reproduction plans, exports, and Core object plans.

Scientific interpretation remains explicit and human-bounded. No automatic prior selection, convergence certification, model selection, causal inference, generalization, scientific-validity certification, or Core submission is performed.
