# Release Notes — Lab v0.135.4

Sustainable Catalyst Lab v0.135.4 adds Interactive Scientific Scene & Visual Drill-Down to the v0.135.1–v0.135.3 visualization sequence. Graph Studio can now expose an explicit multi-layer scientific scene and drill from a visual object into declared data, model, uncertainty, diagnostic, evidence, provenance, spatial, temporal, volume, and trajectory references.

The backend adds scene normalization, explicit hierarchy traversal, detail panels, selection/canvas bridges, mapping validation, viewport/camera/time/slice plans, isolate/compare/trace modes, adaptive LOD and density plans, contextual overlays, deterministic snapshots, exports, and reference-first Platform Core plans. Presentation navigation never mutates the scientific record.
