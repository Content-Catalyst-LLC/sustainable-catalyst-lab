# Deploy Lab backend v0.140.0

Upload `sustainable-catalyst-lab-backend-v0.140.0.zip` and `DEPLOY_LAB_V01400_CONTABO.sh` to `/tmp` on Contabo, then execute the deployment script against the ZIP. The script backs up the live backend, preserves `.env.production`, rebuilds the Lab service, and verifies v0.140.0 plus v0.139.0/v0.138.0/v0.137.0 compatibility.
