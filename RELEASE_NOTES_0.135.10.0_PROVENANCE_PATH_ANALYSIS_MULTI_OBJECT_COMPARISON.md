# Sustainable Catalyst Lab v0.135.10.0
## Provenance Path Analysis, Multi-Object Comparison & Research Context Linking

### Added
- Set selected Graph Studio nodes as comparison Object A and Object B.
- Deterministic bounded shortest-path tracing.
- Directed-lineage and structural-path modes.
- Ordered relationship-chain inspection.
- Incremental node/edge path overlay with no native graph rebuild.
- Project Workspace research-context handoff.
- FastAPI path/compare/context contract endpoints.

### Boundaries
All path results are derived from declared relationships in the loaded graph. The release does not infer causation, evidence support, semantic similarity, ranking, or scientific validity.
